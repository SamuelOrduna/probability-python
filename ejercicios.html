Capítulo 1: Fundamentos de Probabilidad

Ejercicios Fundamentales
1.1

Demostrar que los axiomas de Kolmogorov implican: $P(\emptyset) = 0$, $P(A^c) = 1 - P(A)$, $P(A \cup B) = P(A) + P(B) - P(A \cap B)$

1.2

Sean $A, B, C$ eventos con $P(A) = 0.5$, $P(B) = 0.3$, $P(C) = 0.4$, $P(A \cap B) = 0.15$, $P(A \cap C) = 0.2$, $P(B \cap C) = 0.1$, $P(A \cap B \cap C) = 0.05$. Encontrar $P(A \cup B \cup C)$.

1.3

Probabilidad Condicional: Demostrar que si $B_1, \ldots, B_n$ forman una partición de $\Omega$: $$P(A) = \sum_{i=1}^{n} P(A|B_i)P(B_i)$$

1.4

Teorema de Bayes: Una prueba tiene sensibilidad 0.95 y especificidad 0.97. Prevalencia es 0.001. Si da positiva, ¿cuál es P(enfermedad)?

1.5

Independencia: ¿Si A, B independientes y B, C independientes, entonces A, C independientes? Demostrar o refutar.

Capítulo 2: Variables Aleatorias

Ejercicios sobre Distribuciones
2.1

Sea $X$ con CDF $F_X(x) = \begin{cases} 0 & x < 0 \\ x^2 & 0 \leq x < 1 \\ 1 & x \geq 1 \end{cases}$. Encontrar PDF, $P(0.2 < X \leq 0.8)$, $E[X]$, $\text{Var}(X)$.

2.2

Transformación: Si $X \sim \text{Exponencial}(1)$, encontrar distribución de $Y = X^2$ usando método del Jacobiano.

2.3

LOTUS: Si $X$ tiene PDF $f_X(x) = 2e^{-2x}$ para $x > 0$, encontrar $E[e^{-X}]$.

2.4

Demostrar que $E[(X - E[X])^2] = E[X^2] - (E[X])^2$.

Capítulo 3: Distribuciones Importantes

Ejercicios sobre Distribuciones Clásicas
3.1

Aproximación Poisson: Moneda con $p = 0.001$, 10,000 lanzamientos. Aproximar $P(X=5)$ usando Poisson.

3.2

MGF: Para $X \sim N(0,1)$, $M(t) = e^{t^2/2}$. Encontrar $E[X]$, $E[X^2]$, $\text{Var}(X)$.

3.3

Sea $X \sim \text{Gamma}(\alpha, \beta)$. Demostrar $E[X] = \alpha\beta$ y $\text{Var}(X) = \alpha\beta^2$.

3.4

Sin memoria: Si $X \sim \text{Exponencial}(\lambda)$, demostrar $P(X > s+t | X > s) = P(X > t)$.

Capítulo 4: Distribuciones Multivariadas

Ejercicios sobre Variables Conjuntas
4.1

Sea $(X, Y)$ con $f_{X,Y}(x,y) = 2e^{-(x+y)}$ para $0 < x < y < \infty$. Encontrar marginales y condicional $f_{X|Y}(x|y)$.

4.2

Demostrar: si $X, Y$ independientes, entonces $\text{Cov}(X, Y) = 0$. ¿Es cierto el recíproco?

4.3

Encontrar matriz de covarianza de $(X, Y, Z)$ donde $X \sim N(0,1)$, $Y = 2X + W$, $Z = -X + V$, con $W, V \sim N(0,1)$ independientes.

Capítulo 5: Distribución Normal Multivariada

Ejercicios Avanzados
5.1

Transformación lineal: $\mathbf{X} \sim N_2(\mathbf{0}, I_2)$, $\mathbf{Y} = A\mathbf{X}$ con $A = \begin{pmatrix} 1 & 1 \\ 1 & -1 \end{pmatrix}$. Encontrar distribución de $\mathbf{Y}$.

5.2

Condicionales: $(X, Y) \sim N_2(\mu_X, \mu_Y; \sigma_X^2, \sigma_Y^2, \rho)$. Encontrar $E[Y|X]$ y $\text{Var}(Y|X)$.

5.3

Demostrar: si $(X, Y)$ normal bivariada, entonces $X$ e $Y$ son normales unidimensionales.

5.4

Forma cuadrática: Si $\mathbf{X} \sim N_p(\mathbf{0}, I_p)$, demostrar $\mathbf{X}^T\mathbf{X} \sim \chi^2(p)$.

Recomendaciones para Resolver Ejercicios
  • No mires soluciones inmediatamente: Intenta cada problema sin ayuda durante 30+ minutos
  • Escribe y calcula: Todo en papel, no mentalmente
  • Verifica con Python: Después de resolver, implementa y verifica numéricamente
  • Progresión: Comienza con 1.1-1.5, luego 2.1-2.4, etc.
  • Identifica patrones: Técnicas similares aparecen en diferentes contextos
  • Revisa errores: Entiende exactamente dónde y por qué fallaste
