Capítulo 5: Distribución Normal Multivariada

Objetivos del Capítulo
  • Dominar la distribución Normal multivariada
  • Trabajar con vectores y matrices aleatorios
  • Comprender propiedades de marginalización y condicionalidad
  • Aplicar transformaciones lineales a vectores normales
  • Resolver problemas avanzados en probabilidad multivariada

5.1 Distribución Normal Multivariada: Definición

Definición 5.1.1: Un vector aleatorio $\mathbf{X} = (X_1, \ldots, X_p)^T$ sigue una distribución Normal multivariada si su densidad de probabilidad es: $$f_{\mathbf{X}}(\mathbf{x}) = \frac{1}{(2\pi)^{p/2} |\boldsymbol{\Sigma}|^{1/2}} \exp\left(-\frac{1}{2}(\mathbf{x} - \boldsymbol{\mu})^T \boldsymbol{\Sigma}^{-1} (\mathbf{x} - \boldsymbol{\mu})\right)$$ Notación: $\mathbf{X} \sim N_p(\boldsymbol{\mu}, \boldsymbol{\Sigma})$ donde:
  • $\boldsymbol{\mu} = E[\mathbf{X}]$ es el vector de medias
  • $\boldsymbol{\Sigma} = \text{Var}(\mathbf{X})$ es la matriz de covarianzas

5.2 Propiedades de la Distribución Normal Multivariada

Propiedad 5.2.1 - Transformaciones lineales: Si $\mathbf{X} \sim N_p(\boldsymbol{\mu}, \boldsymbol{\Sigma})$ y $\mathbf{A}$ es una matriz $q \times p$, entonces: $$\mathbf{A}\mathbf{X} \sim N_q(\mathbf{A}\boldsymbol{\mu}, \mathbf{A}\boldsymbol{\Sigma}\mathbf{A}^T)$$
Propiedad 5.2.2 - Marginalización: Las distribuciones marginales de $N_p(\boldsymbol{\mu}, \boldsymbol{\Sigma})$ son normales multivariadas de orden menor.

Específicamente, si $\mathbf{X} \sim N_p(\boldsymbol{\mu}, \boldsymbol{\Sigma})$ y consideramos un subconjunto de coordenadas, éstas siguen una distribución normal multivariada con los correspondientes componentes de $\boldsymbol{\mu}$ y submatriz de $\boldsymbol{\Sigma}$.
Propiedad 5.2.3 - Independencia y normalidad: Si $\mathbf{X} \sim N_p(\boldsymbol{\mu}, \boldsymbol{\Sigma})$, entonces dos componentes $X_i$ y $X_j$ son independientes si y sólo si $\Sigma_{ij} = 0$ (covarianza nula).

5.3 Distribuciones Condicionales

Teorema 5.3.1: Suponga que $\mathbf{X} = \begin{pmatrix} \mathbf{X}_1 \\ \mathbf{X}_2 \end{pmatrix} \sim N\left(\begin{pmatrix} \boldsymbol{\mu}_1 \\ \boldsymbol{\mu}_2 \end{pmatrix}, \begin{pmatrix} \boldsymbol{\Sigma}_{11} & \boldsymbol{\Sigma}_{12} \\ \boldsymbol{\Sigma}_{21} & \boldsymbol{\Sigma}_{22} \end{pmatrix}\right)$ Entonces la distribución condicional de $\mathbf{X}_1$ dado $\mathbf{X}_2 = \mathbf{x}_2$ es normal: $$\mathbf{X}_1 | \mathbf{X}_2 = \mathbf{x}_2 \sim N(\boldsymbol{\mu}_{1|2}, \boldsymbol{\Sigma}_{1|2})$$ donde: $$\boldsymbol{\mu}_{1|2} = \boldsymbol{\mu}_1 + \boldsymbol{\Sigma}_{12}\boldsymbol{\Sigma}_{22}^{-1}(\mathbf{x}_2 - \boldsymbol{\mu}_2)$$ $$\boldsymbol{\Sigma}_{1|2} = \boldsymbol{\Sigma}_{11} - \boldsymbol{\Sigma}_{12}\boldsymbol{\Sigma}_{22}^{-1}\boldsymbol{\Sigma}_{21}$$

5.4 Normal Bivariada

Definición 5.4.1: Una distribución normal bivariada $(X, Y) \sim N_2(\boldsymbol{\mu}, \boldsymbol{\Sigma})$ está completamente determinada por: $$\boldsymbol{\mu} = \begin{pmatrix} \mu_X \\ \mu_Y \end{pmatrix}, \quad \boldsymbol{\Sigma} = \begin{pmatrix} \sigma_X^2 & \rho\sigma_X\sigma_Y \\ \rho\sigma_X\sigma_Y & \sigma_Y^2 \end{pmatrix}$$ donde $\rho$ es el coeficiente de correlación.

5.5 Aplicaciones: Análisis Multivariado

Ejemplo 5.5.1 - Regresión lineal: El problema de predecir $Y$ dado $X$ cuando $(X, Y)$ es normal bivariada. La predicción óptima es: $$E[Y|X=x] = \mu_Y + \rho \frac{\sigma_Y}{\sigma_X}(x - \mu_X)$$ que es la regresión lineal clásica.

5.6 Implementación en Python

import numpy as np
from scipy import stats
import matplotlib.pyplot as plt
from mpl_toolkits.mplot3d import Axes3D

# 1. Distribución Normal bivariada
mu = np.array([0, 0])
sigma = np.array([[1, 0.7], [0.7, 1]])

rv = stats.multivariate_normal(mu, sigma)

# Generar muestras
n_samples = 5000
samples = rv.rvs(n_samples)

# Visualizar
plt.figure(figsize=(12, 5))

plt.subplot(1, 2, 1)
plt.scatter(samples[:, 0], samples[:, 1], alpha=0.3, s=10)
plt.xlabel('X')
plt.ylabel('Y')
plt.title(f'Normal bivariada (ρ = 0.7)')
plt.grid(True, alpha=0.3)
plt.axis('equal')
plt.xlim(-4, 4)
plt.ylim(-4, 4)

# Graficar contornos
x_range = np.linspace(-4, 4, 100)
y_range = np.linspace(-4, 4, 100)
X_grid, Y_grid = np.meshgrid(x_range, y_range)
pos = np.dstack((X_grid, Y_grid))
Z = rv.pdf(pos)

plt.subplot(1, 2, 2)
plt.contourf(X_grid, Y_grid, Z, levels=10, cmap='viridis')
plt.colorbar(label='Densidad')
plt.xlabel('X')
plt.ylabel('Y')
plt.title('Contornos de densidad')
plt.grid(True, alpha=0.3)

plt.tight_layout()
plt.show()

# 2. Propiedades de independencia
# Si correlación = 0, entonces X e Y son independientes
mu_ind = np.array([0, 0])
sigma_ind = np.array([[1, 0], [0, 1]])  # Covarianza nula

rv_ind = stats.multivariate_normal(mu_ind, sigma_ind)
samples_ind = rv_ind.rvs(5000)

plt.figure(figsize=(8, 8))
plt.scatter(samples_ind[:, 0], samples_ind[:, 1], alpha=0.3, s=10)
plt.xlabel('X')
plt.ylabel('Y')
plt.title('Normal bivariada independiente (ρ = 0)')
plt.grid(True, alpha=0.3)
plt.axis('equal')
plt.xlim(-4, 4)
plt.ylim(-4, 4)
plt.show()

# 3. Condicionales: E[Y|X] y distribución condicional
# Para normal bivariada: E[Y|X=x] = μ_Y + ρ(σ_Y/σ_X)(x - μ_X)
rho = 0.7
mu_x, mu_y = 0, 0
sigma_x, sigma_y = 1, 1

x_vals = np.linspace(-3, 3, 10)
conditional_means = mu_y + rho * (sigma_y / sigma_x) * (x_vals - mu_x)

plt.figure(figsize=(10, 6))
plt.scatter(samples[:, 0], samples[:, 1], alpha=0.2, s=10, label='Datos')
plt.plot(x_vals, conditional_means, 'r-', lw=2, label='E[Y|X]')
plt.xlabel('X')
plt.ylabel('Y')
plt.title('Regresión en Normal bivariada')
plt.legend()
plt.grid(True, alpha=0.3)
plt.xlim(-4, 4)
plt.ylim(-4, 4)
plt.show()

# 4. Transformación lineal
# Si X ~ N(μ, Σ), entonces Y = AX ~ N(Aμ, AΣA^T)
A = np.array([[1, 1], [1, -1]])
mu_transformed = A @ mu
sigma_transformed = A @ sigma @ A.T

print("Transformación lineal:")
print(f"A = \n{A}")
print(f"μ_original = {mu}")
print(f"μ_transformada = {mu_transformed}")
print(f"\nΣ_original = \n{sigma}")
print(f"Σ_transformada = \n{sigma_transformed}")

# Verificar con simulación
samples_transformed = (A @ samples.T).T
print(f"\nMedias empíricas transformadas: {np.mean(samples_transformed, axis=0)}")
print(f"Covarianza empírica transformada:\n{np.cov(samples_transformed.T)}")

# 5. Distribución de formas cuadráticas
# Si X ~ N(0, I_p), entonces X^T X ~ χ²(p)
p = 5
samples_standard = np.random.normal(0, 1, (10000, p))
quadratic_forms = np.sum(samples_standard**2, axis=1)

chi2_samples = np.random.chisquare(p, 10000)

plt.figure(figsize=(10, 5))
plt.hist(quadratic_forms, bins=50, density=True, alpha=0.7, label='X^T X')
plt.hist(chi2_samples, bins=50, density=True, alpha=0.7, label='χ²(5)')
plt.xlabel('Valor')
plt.ylabel('Densidad')
plt.title('Forma cuadrática vs χ²')
plt.legend()
plt.grid(True, alpha=0.3)
plt.xlim(0, 20)
plt.show()
