3.1 Distribuciones Discretas

3.1.1 Distribución Bernoulli

Definición 3.1.1: Una variable aleatoria $X$ sigue una distribución Bernoulli con parámetro $p \in [0,1]$ si: $$P(X = k) = p^k (1-p)^{1-k} \quad k \in \{0, 1\}$$ Notación: $X \sim \text{Bernoulli}(p)$

Propiedades: $E[X] = p$, $\text{Var}(X) = p(1-p)$

3.1.2 Distribución Binomial

Definición 3.1.2: Una variable aleatoria $X$ sigue una distribución Binomial si: $$P(X = k) = \binom{n}{k} p^k (1-p)^{n-k} \quad k \in \{0, 1, \ldots, n\}$$ Notación: $X \sim \text{Binomial}(n, p)$

Interpretación: Número de éxitos en $n$ ensayos Bernoulli independientes.

Propiedades: $E[X] = np$, $\text{Var}(X) = np(1-p)$

3.1.3 Distribución Poisson

Definición 3.1.3: Una variable aleatoria $X$ sigue una distribución Poisson con parámetro $\lambda > 0$ si: $$P(X = k) = \frac{\lambda^k e^{-\lambda}}{k!} \quad k \in \{0, 1, 2, \ldots\}$$ Notación: $X \sim \text{Poisson}(\lambda)$

Propiedades: $E[X] = \lambda$, $\text{Var}(X) = \lambda$
Aproximación Binomial a Poisson: Si $n \to \infty$ y $p \to 0$ tal que $np = \lambda$ constante, entonces $\text{Binomial}(n, p) \to \text{Poisson}(\lambda)$.

3.2 Distribuciones Continuas

3.2.1 Distribución Uniforme

Definición 3.2.1: Una variable aleatoria $X$ sigue una distribución Uniforme en $[a, b]$ si: $$f_X(x) = \begin{cases} \frac{1}{b-a} & \text{si } x \in [a, b] \\ 0 & \text{en otro caso} \end{cases}$$ Notación: $X \sim \text{Uniforme}(a, b)$

Propiedades: $E[X] = \frac{a+b}{2}$, $\text{Var}(X) = \frac{(b-a)^2}{12}$

3.2.2 Distribución Normal (Gaussiana)

Definición 3.2.2: Una variable aleatoria $X$ sigue una distribución Normal con parámetros $\mu$ y $\sigma^2$ si: $$f_X(x) = \frac{1}{\sigma\sqrt{2\pi}} \exp\left(-\frac{(x-\mu)^2}{2\sigma^2}\right)$$ Notación: $X \sim N(\mu, \sigma^2)$

Propiedades: $E[X] = \mu$, $\text{Var}(X) = \sigma^2$
Estandarización: Si $X \sim N(\mu, \sigma^2)$, entonces $Z = \frac{X - \mu}{\sigma} \sim N(0, 1)$ (normal estándar).

3.2.3 Distribución Exponencial

Definición 3.2.3: Una variable aleatoria $X$ sigue una distribución Exponencial con parámetro $\lambda > 0$ si: $$f_X(x) = \begin{cases} \lambda e^{-\lambda x} & \text{si } x \geq 0 \\ 0 & \text{en otro caso} \end{cases}$$ Notación: $X \sim \text{Exponencial}(\lambda)$

Propiedades: $E[X] = \frac{1}{\lambda}$, $\text{Var}(X) = \frac{1}{\lambda^2}$

Propiedad sin memoria: $P(X > s + t | X > s) = P(X > t)$ para $s, t \geq 0$

3.2.4 Distribución Gamma

Definición 3.2.4: Una variable aleatoria $X$ sigue una distribución Gamma con parámetros de forma $\alpha > 0$ y escala $\beta > 0$ si: $$f_X(x) = \frac{1}{\beta^\alpha \Gamma(\alpha)} x^{\alpha-1} e^{-x/\beta} \quad x > 0$$ Notación: $X \sim \text{Gamma}(\alpha, \beta)$

Propiedades: $E[X] = \alpha\beta$, $\text{Var}(X) = \alpha\beta^2$

3.3 Función Generadora de Momentos (MGF)

Definición 3.3.1: La función generadora de momentos de una variable aleatoria $X$ es: $$M_X(t) = E[e^{tX}]$$ definida para $t$ en una vecindad de 0.
Propiedad generadora: Si $M_X(t)$ existe en una vecindad de 0: $$M_X^{(n)}(0) = E[X^n] \quad \text{para } n = 1, 2, 3, \ldots$$

3.4 Implementación en Python

import numpy as np
from scipy import stats
import matplotlib.pyplot as plt

# 1. Comparación Binomial vs Poisson
n, p = 100, 0.03
lambda_param = n * p

x_vals = np.arange(0, 10)
pmf_binom = stats.binom.pmf(x_vals, n, p)
pmf_poisson = stats.poisson.pmf(x_vals, lambda_param)

plt.figure(figsize=(10, 5))
plt.bar(x_vals - 0.2, pmf_binom, width=0.4, label=f'Binomial({n}, {p})', alpha=0.7)
plt.bar(x_vals + 0.2, pmf_poisson, width=0.4, label=f'Poisson({lambda_param})', alpha=0.7)
plt.xlabel('k')
plt.ylabel('P(X = k)')
plt.legend()
plt.title('Aproximación Binomial a Poisson')
plt.grid(True, alpha=0.3)
plt.show()

# 2. Distribución Normal y estandarización
mu, sigma = 100, 15
X = stats.norm(mu, sigma)
Z = stats.norm(0, 1)

x_range = np.linspace(mu - 4*sigma, mu + 4*sigma, 200)
pdf_x = X.pdf(x_range)

plt.figure(figsize=(10, 5))
plt.plot(x_range, pdf_x, 'b-', lw=2, label=f'N({mu}, {sigma}²)')
plt.fill_between(x_range, pdf_x, alpha=0.3)
plt.axvline(mu, color='red', linestyle='--', label=f'μ = {mu}')
plt.axvline(mu - sigma, color='green', linestyle=':', label=f'μ ± σ')
plt.axvline(mu + sigma, color='green', linestyle=':')
plt.xlabel('x')
plt.ylabel('f(x)')
plt.legend()
plt.title('Distribución Normal')
plt.grid(True, alpha=0.3)
plt.show()

# 3. Función Generadora de Momentos
# Para Normal(0,1), M(t) = e^(t²/2)
# E[X] = M'(0), E[X²] = M''(0), Var(X) = M''(0) - [M'(0)]²

# Verificación numérica
samples = np.random.normal(0, 1, 100000)
print("Normal(0, 1):")
print(f"E[X] empírico = {np.mean(samples):.4f}")
print(f"E[X²] empírico = {np.mean(samples**2):.4f}")
print(f"Var(X) empírico = {np.var(samples):.4f}")

# 4. Propiedad sin memoria de Exponencial
lambda_exp = 0.5
X_exp = stats.expon(scale=1/lambda_exp)

# P(X > 5 + 3 | X > 5) debería = P(X > 3)
s, t = 5, 3
prob_conditional = (1 - X_exp.cdf(s + t)) / (1 - X_exp.cdf(s))
prob_direct = 1 - X_exp.cdf(t)

print(f"\nPropiedad sin memoria Exponencial({lambda_exp}):")
print(f"P(X > {s+t} | X > {s}) = {prob_conditional:.4f}")
print(f"P(X > {t}) = {prob_direct:.4f}")
print(f"Diferencia = {abs(prob_conditional - prob_direct):.6f}")
