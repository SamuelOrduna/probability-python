Capítulo 2: Variables Aleatorias

Objetivos del Capítulo
  • Entender la definición formal de variable aleatoria
  • Trabajar con funciones de distribución acumulada (CDF)
  • Diferenciar entre variables discretas y continuas
  • Calcular esperanza, varianza y momentos
  • Aplicar transformaciones de variables aleatorias

2.1 Definición Formal de Variable Aleatoria

Definición 2.1.1: Sea $(\Omega, \mathcal{F}, P)$ un espacio de probabilidad. Una variable aleatoria es una función: $$X: \Omega \to \mathbb{R}$$ tal que para todo $a \in \mathbb{R}$, el conjunto $\{w \in \Omega : X(w) \leq a\}$ pertenece a $\mathcal{F}$.

Una variable aleatoria nos permite asignar números a los resultados de un experimento aleatorio, transformando el espacio muestral en la recta real.

2.2 Función de Distribución Acumulada (CDF)

Definición 2.2.1: La función de distribución acumulada (CDF) de una variable aleatoria $X$ es: $$F_X(x) = P(X \leq x) \quad \forall x \in \mathbb{R}$$
Propiedades del CDF:
  1. $0 \leq F_X(x) \leq 1$ para todo $x$
  2. $F_X$ es no decreciente
  3. $\lim_{x \to -\infty} F_X(x) = 0$ y $\lim_{x \to \infty} F_X(x) = 1$
  4. $F_X$ es continua por la derecha
  5. $P(a < X \leq b) = F_X(b) - F_X(a)$ para $a < b$

2.3 Variables Aleatorias Discretas

Definición 2.3.1: Una variable aleatoria $X$ es discreta si toma valores en un conjunto finito o numerable. La función de masa de probabilidad (PMF) es: $$p_X(x) = P(X = x)$$
Propiedades del PMF:
  1. $p_X(x) \geq 0$ para todo $x$ en el soporte de $X$
  2. $\sum_x p_X(x) = 1$
  3. $F_X(x) = \sum_{t \leq x} p_X(t)$

2.4 Variables Aleatorias Continuas

Definición 2.4.1: Una variable aleatoria $X$ es continua si existe una función $f_X(x) \geq 0$ tal que: $$F_X(x) = \int_{-\infty}^{x} f_X(t) \, dt$$ La función $f_X$ se llama función de densidad de probabilidad (PDF).
Propiedades del PDF:
  1. $f_X(x) \geq 0$ para todo $x$
  2. $\int_{-\infty}^{\infty} f_X(x) \, dx = 1$
  3. $f_X(x) = \frac{d}{dx} F_X(x)$ (donde existe la derivada)
  4. $P(a < X \leq b) = \int_a^b f_X(x) \, dx$

2.5 Esperanza y Momentos

Definición 2.5.1: La esperanza o valor esperado de una variable aleatoria $X$ es: $$E[X] = \begin{cases} \sum_x x \cdot p_X(x) & \text{si } X \text{ es discreta} \\ \int_{-\infty}^{\infty} x \cdot f_X(x) \, dx & \text{si } X \text{ es continua} \end{cases}$$
Ley del Estadístico Inconsciente (LOTUS): Para cualquier función $g$: $$E[g(X)] = \begin{cases} \sum_x g(x) \cdot p_X(x) & \text{si } X \text{ es discreta} \\ \int_{-\infty}^{\infty} g(x) \cdot f_X(x) \, dx & \text{si } X \text{ es continua} \end{cases}$$
Definición 2.5.2: La varianza de $X$ es: $$\text{Var}(X) = E[(X - E[X])^2] = E[X^2] - (E[X])^2$$ La desviación estándar es $\sigma_X = \sqrt{\text{Var}(X)}$.
Propiedades de la Esperanza y Varianza:
  1. $E[aX + b] = aE[X] + b$
  2. $\text{Var}(aX + b) = a^2 \text{Var}(X)$
  3. $E[X + Y] = E[X] + E[Y]$ (siempre)
  4. Si $X, Y$ independientes: $\text{Var}(X + Y) = \text{Var}(X) + \text{Var}(Y)$

2.6 Transformación de Variables Aleatorias

Cambio de Variable (Método del Jacobiano): Si $X$ es continua con PDF $f_X(x)$ y $Y = g(X)$ donde $g$ es monótona y diferenciable, entonces: $$f_Y(y) = f_X(g^{-1}(y)) \left| \frac{d}{dy} g^{-1}(y) \right|$$
Ejemplo 2.6.1: Si $X \sim \text{Uniforme}(0,1)$, encontrar la distribución de $Y = -\ln(X)$.

Como $y = -\ln(x)$, tenemos $x = e^{-y}$, entonces: $$f_Y(y) = f_X(e^{-y}) \cdot e^{-y} = 1 \cdot e^{-y} = e^{-y} \quad (y > 0)$$ Por lo tanto, $Y \sim \text{Exponencial}(1)$.

2.7 Implementación en Python

import numpy as np
import matplotlib.pyplot as plt
from scipy import stats

# Ejemplo 1: Variable discreta (Binomial)
n, p = 20, 0.4
X_binom = stats.binom(n, p)

print("Variable Discreta: Binomial(20, 0.4)")
print(f"E[X] = {X_binom.mean():.4f}")
print(f"Var(X) = {X_binom.var():.4f}")
print(f"σ = {X_binom.std():.4f}")

# Graficar PMF
x_vals = np.arange(0, n+1)
pmf_vals = X_binom.pmf(x_vals)
plt.figure(figsize=(10, 5))
plt.bar(x_vals, pmf_vals, alpha=0.7, color='blue')
plt.xlabel('x')
plt.ylabel('P(X = x)')
plt.title('PMF de Binomial(20, 0.4)')
plt.grid(True, alpha=0.3)
plt.show()

# Ejemplo 2: Variable continua (Normal)
mu, sigma = 0, 1
X_normal = stats.norm(mu, sigma)

print(f"\nVariable Continua: Normal(0, 1)")
print(f"E[X] = {X_normal.mean():.4f}")
print(f"Var(X) = {X_normal.var():.4f}")

# Graficar PDF
x_cont = np.linspace(-4, 4, 1000)
pdf_vals = X_normal.pdf(x_cont)
plt.figure(figsize=(10, 5))
plt.plot(x_cont, pdf_vals, 'b-', lw=2)
plt.fill_between(x_cont, pdf_vals, alpha=0.3)
plt.xlabel('x')
plt.ylabel('f(x)')
plt.title('PDF de Normal(0, 1)')
plt.grid(True, alpha=0.3)
plt.show()

# Ejemplo 3: Transformación de variable (Log-Normal)
# Si X ~ Normal(0,1), entonces Y = e^X ~ LogNormal
np.random.seed(42)
X_samples = np.random.normal(0, 1, 10000)
Y_samples = np.exp(X_samples)

plt.figure(figsize=(12, 5))

plt.subplot(1, 2, 1)
plt.hist(X_samples, bins=50, density=True, alpha=0.7, color='blue')
x_range = np.linspace(-4, 4, 200)
plt.plot(x_range, stats.norm.pdf(x_range), 'r-', lw=2)
plt.xlabel('x')
plt.ylabel('Densidad')
plt.title('X ~ Normal(0, 1)')
plt.grid(True, alpha=0.3)

plt.subplot(1, 2, 2)
plt.hist(Y_samples, bins=50, density=True, alpha=0.7, color='green')
y_range = np.linspace(0.1, 10, 200)
plt.plot(y_range, stats.lognorm.pdf(y_range, 1), 'r-', lw=2)
plt.xlabel('y')
plt.ylabel('Densidad')
plt.title('Y = exp(X) ~ LogNormal')
plt.grid(True, alpha=0.3)
plt.xlim(0, 10)

plt.tight_layout()
plt.show()

# Ejemplo 4: Verificación de LOTUS
# E[X^2] calculado directamente vs vía integral
X = stats.uniform(0, 2)
# Método 1: E[X^2] directamente = ∫ x^2 * f(x) dx
# Para Uniform(0,2): f(x) = 1/2
# E[X^2] = ∫_0^2 x^2 * (1/2) dx = [x^3/6]_0^2 = 8/6 = 4/3
print(f"\nVerificación de LOTUS:")
print(f"E[X^2] teórico = 4/3 = {4/3:.4f}")
samples = X.rvs(100000)
print(f"E[X^2] empírico = {np.mean(samples**2):.4f}")
