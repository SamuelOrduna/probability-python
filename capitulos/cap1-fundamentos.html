Capítulo 1: Fundamentos de Probabilidad

Objetivos del Capítulo
  • Comprender los axiomas de Kolmogorov y sus implicaciones
  • Dominar técnicas de conteo para espacios finitos
  • Aprender probabilidad condicional e independencia de eventos
  • Aplicar el Teorema de Bayes en contextos reales
  • Trabajar con espacios de probabilidad abstractos

1.1 Espacios de Probabilidad y Axiomas

Definición 1.1.1: Un espacio de probabilidad es una terna $(\Omega, \mathcal{F}, P)$ donde:
  • $\Omega$ es el espacio muestral (conjunto de todos los posibles resultados)
  • $\mathcal{F}$ es una sigma-álgebra (colección de subconjuntos de $\Omega$ que llamamos eventos)
  • $P: \mathcal{F} \to [0,1]$ es una medida de probabilidad
Axiomas de Kolmogorov: La función $P$ debe satisfacer:
  1. $P(A) \geq 0$ para todo $A \in \mathcal{F}$
  2. $P(\Omega) = 1$
  3. Para eventos $A_1, A_2, \ldots$ disjuntos en $\mathcal{F}$: $$P\left(\bigcup_{i=1}^{\infty} A_i\right) = \sum_{i=1}^{\infty} P(A_i)$$

1.2 Propiedades Fundamentales

Teorema 1.2.1: Sea $(\Omega, \mathcal{F}, P)$ un espacio de probabilidad. Entonces:
  1. $P(\emptyset) = 0$
  2. $P(A^c) = 1 - P(A)$ para todo $A \in \mathcal{F}$
  3. $P(A \cup B) = P(A) + P(B) - P(A \cap B)$ para $A, B \in \mathcal{F}$
  4. Si $A \subseteq B$, entonces $P(A) \leq P(B)$

1.3 Técnicas de Conteo

Para espacios finitos, la probabilidad de un evento es el cociente entre casos favorables y casos totales.

Principio Multiplicativo: Si un experimento consta de $k$ etapas, donde la $i$-ésima etapa tiene $n_i$ posibilidades, el número total de resultados es: $$N = n_1 \cdot n_2 \cdot \ldots \cdot n_k$$
Ejemplo 1.3.1: Permutaciones. El número de formas de ordenar $n$ objetos distintos es: $$P(n) = n! = n \cdot (n-1) \cdot \ldots \cdot 1$$ El número de formas de seleccionar $k$ objetos de $n$ donde el orden importa es: $$P(n,k) = \frac{n!}{(n-k)!}$$
Ejemplo 1.3.2: Combinaciones. El número de formas de seleccionar $k$ objetos de $n$ donde el orden NO importa es: $$\binom{n}{k} = \frac{n!}{k!(n-k)!}$$

1.4 Probabilidad Condicional

Definición 1.4.1: Sean $A, B \in \mathcal{F}$ con $P(B) > 0$. La probabilidad condicional de $A$ dado $B$ es: $$P(A|B) = \frac{P(A \cap B)}{P(B)}$$
Regla de la Cadena: Para eventos $A_1, A_2, \ldots, A_n$: $$P(A_1 \cap A_2 \cap \ldots \cap A_n) = P(A_1) \cdot P(A_2|A_1) \cdot P(A_3|A_1 \cap A_2) \cdots P(A_n|A_1 \cap \ldots \cap A_{n-1})$$

1.5 Independencia de Eventos

Definición 1.5.1: Dos eventos $A$ y $B$ son independientes si: $$P(A \cap B) = P(A) \cdot P(B)$$ De manera equivalente, si $P(B) > 0$: $P(A|B) = P(A)$
Definición 1.5.2: Los eventos $A_1, A_2, \ldots, A_n$ son mutuamente independientes si para todo subconjunto $\{i_1, \ldots, i_k\} \subseteq \{1, \ldots, n\}$: $$P\left(\bigcap_{j=1}^{k} A_{i_j}\right) = \prod_{j=1}^{k} P(A_{i_j})$$

1.6 Teorema de Bayes

Ley de Probabilidad Total: Si $B_1, B_2, \ldots, B_n$ es una partición de $\Omega$ (eventos disjuntos que cubren $\Omega$), entonces: $$P(A) = \sum_{i=1}^{n} P(A|B_i) \cdot P(B_i)$$
Teorema de Bayes: Con la notación anterior: $$P(B_i|A) = \frac{P(A|B_i) \cdot P(B_i)}{\sum_{j=1}^{n} P(A|B_j) \cdot P(B_j)}$$
Ejemplo 1.6.1: Prueba diagnóstica. Una enfermedad afecta al 1% de la población. Una prueba tiene 99% de sensibilidad (detecta el 99% de enfermos) y 98% de especificidad (da negativo en el 98% de sanos).

Si una persona da positivo en la prueba, ¿cuál es la probabilidad de que realmente esté enferma?

Sean: $D$ = "tener la enfermedad", $+$ = "resultado positivo"
  • $P(D) = 0.01$, $P(D^c) = 0.99$
  • $P(+|D) = 0.99$, $P(+|D^c) = 0.02$
  • $P(D|+) = \frac{0.99 \cdot 0.01}{0.99 \cdot 0.01 + 0.02 \cdot 0.99} = \frac{0.0099}{0.0297} \approx 0.333$
A pesar de que la prueba es confiable, el resultado positivo da solo ~33% de probabilidad de realmente tener la enfermedad.

1.7 Implementación en Python

Veamos cómo implementar conceptos de probabilidad básica en Python:

import numpy as np
from itertools import combinations, permutations
from math import factorial, comb

# Conteo combinatorio
n, k = 10, 3

# Permutaciones
def perm(n, k):
    return factorial(n) // factorial(n - k)

print(f"P(10,3) = {perm(10, 3)}")  # 720

# Combinaciones (usando la función built-in)
print(f"C(10,3) = {comb(10, 3)}")  # 120

# Paradoja del Cumpleaños
def birthday_paradox(n_people):
    """Probabilidad de que al menos 2 personas
    compartan cumpleaños en grupo de n_people"""
    if n_people > 365:
        return 1.0
    prob_different = 1.0
    for i in range(n_people):
        prob_different *= (365 - i) / 365
    return 1 - prob_different

for n in [20, 23, 30, 50]:
    prob = birthday_paradox(n)
    print(f"n={n}: P(compartir cumpleaños) = {prob:.4f}")

# Teorema de Bayes: Ejemplo de prueba médica
def bayes_medical_test(p_disease, sensitivity, specificity):
    """
    Calcula P(enfermedad | resultado positivo)
    """
    p_positive_given_disease = sensitivity
    p_positive_given_healthy = 1 - specificity
    p_healthy = 1 - p_disease

    # Probabilidad total de positivo
    p_positive = (p_positive_given_disease * p_disease +
                  p_positive_given_healthy * p_healthy)

    # Bayes
    p_disease_given_positive = (p_positive_given_disease * p_disease) / p_positive

    return p_disease_given_positive

result = bayes_medical_test(0.01, 0.99, 0.98)
print(f"\nP(enfermedad | +) = {result:.4f}")  # 0.3333

# Simulación de eventos independientes
def simulate_independent_events(n_trials=10000):
    """Simula P(A ∩ B) para eventos independientes"""
    np.random.seed(42)

    # Evento A: resultado de dado > 3 (P(A) = 0.5)
    # Evento B: moneda sale cara (P(B) = 0.5)

    dice_rolls = np.random.randint(1, 7, n_trials)
    coin_flips = np.random.randint(0, 2, n_trials)

    A = dice_rolls > 3  # P(A) ≈ 0.5
    B = coin_flips == 1  # P(B) ≈ 0.5

    p_a = np.mean(A)
    p_b = np.mean(B)
    p_a_and_b = np.mean(A & B)

    print(f"\nSimulación de independencia:")
    print(f"P(A) = {p_a:.4f}")
    print(f"P(B) = {p_b:.4f}")
    print(f"P(A ∩ B) = {p_a_and_b:.4f}")
    print(f"P(A) × P(B) = {p_a * p_b:.4f}")
    print(f"Diferencia = {abs(p_a_and_b - p_a * p_b):.4f}")

simulate_independent_events()
